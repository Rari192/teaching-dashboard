# Teaching Dashboard

A personal, offline-first teaching companion for iPad mini.

- Open it once at its GitHub Pages address, then use Share › Add to Home Screen.
- All classes and timetable data are stored only on the device (IndexedDB). Nothing personal is in this repository.
- To publish an update, change `APP_VERSION` in `sw.js`. The iPad picks it up the next time the app is fully closed and reopened.
- `run-tests.html` runs the logic and storage tests in the browser.
